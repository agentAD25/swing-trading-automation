# Research Workstreams

Phase 1B consists of three independent, non-implementation workstreams:

1. Broker/API — public interfaces, simulation, market data, constraints, and
   order lifecycle
2. Strategy/data — testable requirements, data characteristics, and validation
   methodology
3. Risk/operations — safety controls, failure modes, reconciliation,
   observability, and auditability

No workstream may use credentials, access an account, submit an order, begin
foundation implementation, or make an architecture decision.

## Required handoff

Each finding must include:

- statement classified as fact, inference, assumption, or open question;
- source title and publisher;
- canonical URL or repository reference;
- access date;
- exact claim the source supports;
- relevant quotation or section locator where practical;
- limitations, ambiguity, conflicts, and confidence;
- implications framed as candidates, not decisions; and
- unresolved questions requiring reconciliation or human input.

Prefer first-party sources. Record conflicting evidence without silently
choosing a winner. Research outputs must state that `SIM` is the only
authorized mode and that `LIVE` is unauthorized.
