# Architecture Decision Records

Use `ADR-TEMPLATE.md` for material architecture and safety decisions. Name
records `NNNN-short-title.md`, retain their history, and use one of:
`Proposed`, `Accepted`, `Rejected`, `Superseded`, or `Deprecated`.

Only identified human deciders may move an ADR to `Accepted`. An accepted ADR
does not by itself authorize a phase transition or `LIVE` activity; authority
must also be explicit in `docs/CURRENT_STATE.md` and human instructions.
