# Architecture Decision Records

Use `ADR-TEMPLATE.md` for material architecture and safety decisions. Name
records `NNNN-short-title.md`, retain their history, and use one of:
`Proposed`, `Accepted`, `Rejected`, `Superseded`, or `Deprecated`.

Only the Operator acting as sole decider may move an ADR to `Accepted`. An
accepted ADR does not by itself authorize implementation, credentials,
broker/network/account activity, TradeStation `SIM`, a phase transition, or
`LIVE`. Every governing conjunctive gate and an explicit Operator decision in
`docs/CURRENT_STATE.md` are also required. Safety prohibitions are
non-overridable while current state denies the capability.
